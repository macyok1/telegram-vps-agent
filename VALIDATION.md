# Проверка комплекта

5 октября 2026 года перед первой публикацией выполнено локально на Windows / Python 3.12:

- `compileall` всех `apps` и `scripts`: успешно.
- Существующие тесты бота: 60 тестов, 55 выполнено успешно, 5 пропущены из-за Linux fcntl.
- Существующие тесты web-chat store: 5 тестов, все успешно.
- `bash -n scripts/install.sh` через Git Bash: успешно.
- Проверка staged-файлов на закрытые runtime-файлы, формы токенов и исходные серверные адреса: успешно.
- `git diff --cached --check`: успешно.

Полный Linux-набор, Compose, systemd и установка с реальным безвредным заданием
брокера проверяются в GitHub Actions. Результат конкретного запуска виден во вкладке
Actions репозитория. Smoke запускается на одноразовом CI runner, а не на VPS автора.
Он не обращается к Telegram/LLM и не запускает настоящий Telegram polling.

Установка с настоящими токенами, выбранным провайдером и переписка нового владельца
не проверялись при сборке: это заключительный этап SETUP.md на его собственном сервере.
Сам gateway-контейнер в этой сборке не запускался; CI проверяет конфигурацию Compose.
Проверка форм токенов не является доказательством отсутствия любого возможного секрета;
для публикации также использован явный список исходных файлов, без private env/state.
